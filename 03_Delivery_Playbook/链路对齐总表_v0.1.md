## 4｜四个裁决项

> **性质声明（2026-08-18 返工补记）**：R-1~R-4 均为**可逆的通元问科设计选择/候选落位**（DEC-2026-013），不是行业事实，也不改变十阶段链的整体 HYPOTHESIS 状态；GATE-0~7 全部未经真实项目执行。所有「裁决」在真实 Gate 运行验证前均为候选映射/设计决定。

### R-1｜Baseline 的链路位置 → B 类建议（不改变阶段数量）
- **建议**：Baseline 保持为**阶段 02 的核心作业**（TOOL-004 已建于该位）+ GATE-2 的证据项；**不升独立阶段、不并入 GATE-2 取消阶段位**。
- **证据**：手册 L2 八查含「能形成现状基线」且退回条件含「建议指标尚未建立现状基线」（准入视角）；瓴羊三支柱把「业务过往历史记录→测评级」作为 FDE 前置而非独立阶段（EV-LY-001①）；OpenAI eval 方法从业务指标出发（EV-EXT-007①）。
- **影响**：无结构变化；GATE-2 语义微调为「核心业务指标与基线存在」（文案级）。
- **C 类触发**：若现场发现基线工作量大到需要独立立项/独立合同（瓴羊式付费诊断）→ 届时出 Change Proposal 增设阶段或子阶段。

### R-2｜Human Benchmark / Work Trace 的链路位置 → B 类建议
- **建议**：**WT=阶段 03 的主体作业**（TOOL-006 已建于该位）；**HB=横跨 02-03 的作业对象**（选例与实测在 02-03，产出喂 06 Eval）；两者均为**作业对象而非阶段**，不新增阶段位。
- **证据**：TOOL-005/006 落位即此；手册第 3 章「现场调查与任务拆解」天然容纳两者；瓴羊「岗位标杆为预设」出现在准入讨论中（EV-LY-001①）而非独立交付阶段。
- **影响**：Master Index DEL-008/009 文案已含落位，无需改。

### R-3｜客户采用/业务结果/ROI 的位置 → B 类建议 + C 类备选（不执行）
- **B 类建议（推荐）**：并入**阶段 08 Production 的 Exit 必查维度** + **GATE-7 的证据输入**。即在 08 的阶段卡 Exit 中显式列出「实际使用率/业务结果口径/ROI 对照（对 TOOL-004 基线）」，不设独立阶段。
- **证据**：官网五阶段第 5 步已含「实际使用、风险可控且维护责任明确时才扩大」（采用内嵌于运营）；瓴羊「交付完 Agent 或系统才刚刚开始…用业务结果买单」（EV-LY-001 [18:11]）；手册第 7 章内容（采用/结果/ROI）本质是运营期度量而非独立工序。
- **C 类备选（仅记录，不执行）**：若未来发现采用工作需要独立准入（如客户采用咨询作为可售服务），可提案在 07 与 08 之间增设「07a 采用确认」阶段——触发条件写入本表，届时走 Change Proposal。

### R-4｜Gate 体系与 L0-L5 的关系 → B 类建议（映射表固化）
- **建议**：采纳 D-5 的多对多映射作为正式说明写入 IA 附注；**GATE 语义候选维持不变**（GATE-0~7 未在任何真实项目中执行过，全部 HYPOTHESIS）；L0-L5 已经过一次历史回放（内部演练级），在准入区间（GATE-0/1）它是**实现件**，此后区间它是**并行轨道**（每级工作都仍受后续 Gate 约束）。
- **影响**：IA §5 增加一句多对多说明（文案级）；不新增、不合并、不重排。

## 7｜使用状态、交付入口与反馈路由（2026-08-18 增补，Issue #4 获批，DEC-2026-015）

### 7.1 五级使用状态（不新增阶段/闸门；GATE-6 语义不变=判断生产风险是否可接受）
| 级 | 状态 | 判定事实 |
|---|---|---|
| U1 | 原型验证通过 | **离线/受控环境的历史回测或评测**达标，GATE-5 通过（影子运行属 U3，不计入 U1） |
| U2 | 上线准备就绪 | 权限/数据/日志/回滚/维护责任就位（GATE-6 判断本级风险） |
| U3 | 受控上线 | 真实环境中的受控部署入口/运行通道已对**指定用户或影子观察角色**启用 |
| U4 | 真实使用已发生 | **第一条符合条件的真实用户任务轨迹**产生（TOOL-007 判定；纯影子输出未被真实用户用于完成业务任务的，只证明 U3 运行，不得标 U4） |
| U5 | 现场验证 | 重复、具代表性的使用与结果证据（不可由一次使用推出；「代表性」确认方与依据由 TOOL-007 登记，量化阈值未知） |

三条铁律：一次轨迹≠使用率；一次使用≠现场验证；原始轨迹≠评测集。

### 7.2 真实交付入口统一定义（不限 URL）
获授权的真实用户，通过客户实际允许的交付入口，在真实工作环境中完成真实业务任务，并留下可追溯结果。入口包括 URL/ERP/WMS/CRM 内嵌页/内网工作台/API/批处理/审批消息流/桌面工具——URL 合法，但「有 URL」≠已交付。

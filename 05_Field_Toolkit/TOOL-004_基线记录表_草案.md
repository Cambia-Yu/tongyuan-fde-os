# TOOL-004｜基线记录表（Baseline Sheet）草案

## Purpose｜为什么存在
没有基线，一切「提升 X%」都无法验证，只能事后发明指标（企业常见失败模式）。本表在 AI 介入**之前**把「这项工作现在实际做到什么水平」测成可复核的数字，服务三处：GATE-2 放行证据、MVP 价值对照（DEL-005 指标纪律）、合同/官网效果表述边界（COM-007）。

## Entry Criteria｜进入条件
- 已有明确任务单元（L2 准入通过，〔作业-准入-02〕在案）；
- 已取得可访问的数据来源或可观察的实际操作人员（至少 1 名）；
- 客户已书面同意提供统计所需数据或允许现场测量（口头不算）。

## Actions｜怎么做
1. **定口径**：先填「统计范围/时间窗口/样本来源/含排除项」四字段，再谈数字；口径未定不得填数。
2. **测四维**：成本（人日/单价）、时长（分布，报中位数与 P90，不报均值）、质量（错误率/返工率/异常率，按规则或类型分桶）、量（总量/人均）。
3. **交叉验证**：系统日志口径与操作人口述对不上时，以可追溯来源为准并记录差值（对接证据六级优先级）。
4. **锁定**：基线确认后由业务负责人签字，写入 GATE-2 证据包；此后不得回改，修正须新开一行并注明原因。

## Exit Criteria｜做到什么程度算完成
- 四维字段全部为「实测值」或明确标注「无法测量+原因+替代口径」；
- 每个数字有来源（系统名/表名/观察记录编号）；
- 业务负责人签字确认口径与数值。

## Artifacts / Fields｜留什么
| 字段 | 填写要求 |
|---|---|
| 任务单元名称/编号 | 与准入记录一致 |
| 统计范围 | 哪个岗位/哪类单据/哪个环节 |
| 时间窗口 | 起止日期，≥1 个完整业务周期 |
| 样本来源 | 系统名/表/导出方式或观察对象（脱敏） |
| 排除项 | 明确不计入的情形（如退回件、系统故障期） |
| 成本基线 | 人日×单价；口径注明 |
| 时长基线 | 中位数 / P90 / 样本量 n |
| 质量基线 | 错误率/异常率 + 分桶口径 |
| 量基线 | 总量、人均、峰值日 |
| 口径争议记录 | 谁说的、差异、裁决人与依据 |
| 确认 | 业务负责人/日期/签字 |

## Hold 条件｜什么情况下停
- 只有单次/单例记录（如「上次那笔花了两天」）→ **不构成基线**，不得填入实测值；
- 统计窗口不足一个业务周期 → 标「初步值」，不得用于承诺；
- 数据只能口述取得 → 停在 L1，返回〔作业-准入-01〕补证据；
- 口径冲突未裁决 → 可以继续测量，但不得进入评测与 ROI 计算（R-C04）。
